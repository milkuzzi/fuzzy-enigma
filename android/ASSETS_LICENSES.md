# Ассеты оформления (dungeon-стиль)

## Шрифты (res/font)

Все шрифты распространяются по лицензии **SIL Open Font License 1.1 (OFL)** и
получены из репозитория Google Fonts (https://github.com/google/fonts):

| Файл | Семейство | Автор / Источник | Лицензия |
| --- | --- | --- | --- |
| `ruslandisplay.ttf` | Ruslan Display | Pavel Emelyanov / Google Fonts | OFL 1.1 |
| `medievalsharp.ttf` | MedievalSharp | Wojciech Kalinowski / Google Fonts | OFL 1.1 |
| `pressstart2p.ttf` | Press Start 2P | CodeMan38 / Google Fonts | OFL 1.1 |

Ruslan Display и Press Start 2P содержат глифы кириллицы и используются для
заголовков и цифр таймера; MedievalSharp (латиница) — только для названия
«Study Dungeon».

Текст лицензии OFL: https://openfontlicense.org

## Спрайты (res/drawable-nodpi)

Пиксель-арт спрайты (`bg_dungeon_wall`, `hero_portrait`, `ic_hp`, `ic_gold`,
`ic_xp`, `ic_potion`, `ic_scroll`, `ic_hourglass`) сгенерированы специально для
этого проекта и могут свободно использоваться в рамках репозитория.
